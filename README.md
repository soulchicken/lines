# Lines

맥북 강의용 메뉴 막대 필기 앱입니다. 펜에 흰 테두리가 있어 밝은 슬라이드와 어두운 편집기 위에서 모두 사용할 수 있습니다.

1. Finder에서 `Lines.app`을 열면 메뉴 막대에 연필 아이콘이 생깁니다.
2. 필기할 화면에 포인터를 놓고 `Control + Option + D`를 누릅니다. 마우스나 트랙패드로 드래그해 선을 긋고, 클릭해 점을 찍습니다.
3. 필기 중 숫자 키 `1` 빨강, `2` 파랑, `3` 초록, `4` 노랑으로 다음 획의 색을 고릅니다. 화면을 우클릭하거나 메뉴 막대의 **펜 색상**에서도 선택할 수 있습니다. 마지막으로 선택한 색은 다음 실행에도 유지됩니다.
4. `⌘Z`를 누를 때마다 마지막 필기 동작을 하나씩 취소합니다. `Delete`로 모두 지운 직후에 누르면 지웠던 획이 원래 색으로 돌아옵니다.
5. `Esc` 또는 `Control + Option + D`로 필기를 마치면 선과 취소 기록이 지워지고 강의 화면을 다시 조작할 수 있습니다.

필기 시작은 메뉴 막대에서도 선택할 수 있습니다. 온라인 강의에서 필기를 함께 보여주려면 필기할 디스플레이 전체를 공유하세요. 앱 창 하나만 공유하면 별도 창에 그린 필기가 빠질 수 있습니다.

## 소스에서 실행

macOS 14 이상과 Xcode Command Line Tools가 있는 Mac에서 프로젝트 폴더의 `make run`을 실행하세요. `make`는 현재 Mac용 `Lines.app`을 빌드하고 로컬 서명합니다.

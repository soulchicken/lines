# Lines

macOS 메뉴 막대에서 실행하는 강의용 화면 필기 앱입니다. 슬라이드나 코드 위에 펜으로 쓰고, 레이저 포인터로 내용을 짚고, 필기한 화면을 PNG로 저장할 수 있습니다.

도구별 동작과 설정 규칙은 [기능 명세](SPEC.md)에 정리했습니다.

## 다른 Mac에서 실행하기

macOS 14 Sonoma 이상이 필요합니다. 사용할 Mac에서 소스를 빌드하면 해당 Mac용 `Lines.app`이 만들어집니다.

1. **개발 도구 설치.** 터미널에서 다음 명령을 실행하고 설치 창의 안내를 따르세요. Xcode 또는 Command Line Tools가 이미 설치되어 있다면 다음 단계로 넘어가세요. 빌드에는 macOS 14 이상의 SDK가 필요합니다.

   ```sh
   xcode-select --install
   ```

2. **소스 받기.** 이 GitHub 저장소의 **Code → Download ZIP**을 눌러 압축을 풉니다. Git을 쓴다면 **Code → HTTPS**에서 주소를 복사해 `git clone`으로 받아도 됩니다.
3. **프로젝트 폴더 열기.** 터미널에 `cd`와 공백 하나를 입력하고, Finder에서 `Makefile`이 들어 있는 폴더를 터미널로 끌어다 놓은 뒤 Return을 누르세요.
4. **빌드하고 실행하기.**

   ```sh
   make run
   ```

메뉴 막대에 펜촉 아이콘이 보이면 실행된 상태입니다. 다음부터는 Finder에서 프로젝트 폴더의 `Lines.app`을 더블클릭하세요. 응용 프로그램 폴더에 복사해서 써도 됩니다.

## 첫 필기

발표할 디스플레이에 포인터를 놓고 **⌥ Option + 백틱**을 누르세요. 드래그하면 선이 그려지고 클릭하면 점이 찍힙니다. **Esc**를 누르면 필기가 지워지고 발표 화면으로 돌아갑니다. 필기를 보관하려면 종료 전에 캡처하세요.

| 기본 단축키 | 동작 |
| --- | --- |
| ⌥ Option + 백틱 (`` ` ``) | 다른 앱에서도 필기 시작 또는 마치기 |
| `1` / `2` / `3` / `4` | 다음 획의 색을 빨강 / 파랑 / 초록 / 노랑으로 변경 |
| `Q` / `W` / `E` / `R` / `A` | 펜 / 직선 / 사각형 / 텍스트 / 레이저 선택 |
| `⌘Z` | 마지막 획 취소. 전체 지우기 직후에는 지운 획 복원 |
| `Delete` | 필기 전체 지우기 |
| `⌘S` | 현재 디스플레이와 필기를 PNG로 저장 |
| `⌘,` | 필기 중 단축키 설정 열기 |
| `Esc` | 필기 마치기 |

- **도구 색상**은 상단의 색상 동그라미를 눌러 고를 수 있습니다. 동그라미에는 현재 필기 색이나 레이저 색이 표시됩니다.
- **직선** 버튼을 누르고 시작점에서 끝점까지 드래그하세요. **⌥ Option**을 누른 채 마우스를 놓으면 드래그한 끝에 화살촉이 붙습니다.
- **사각형** 버튼을 누르고 한 모서리에서 반대쪽 모서리까지 드래그하면 현재 펜 색으로 테두리가 그려집니다. **펜**을 누르면 다시 자유롭게 필기할 수 있습니다.
- **텍스트** 버튼을 누르고 화면을 클릭해 글을 입력하세요. `Return`으로 줄을 바꾸고, `⌘Return`을 누르거나 상자 밖을 클릭하면 현재 펜 색으로 확정됩니다. 입력 중 `Esc`로 취소할 수 있습니다. 텍스트 도구에서 이미 확정한 글을 드래그하면 옮길 수 있고, `⌘Z`로 이전 위치에 되돌릴 수 있습니다.
- **서식**은 기존 선, 화살표, 사각형 테두리, 텍스트 위에서 우클릭해 바꿀 수 있습니다. 선과 도형의 **선 굵기**, 텍스트의 **글자 크기**, **글자 굵기**, **기울임**을 선택할 수 있습니다. 빈 곳을 우클릭하면 현재 도구의 다음 입력에 적용할 서식을 고를 수 있습니다.
- **레이저 포인터**를 선택하면 빛나는 색 점이 마우스 커서를 따라옵니다. 누른 채 움직이면 꼬리가 남고, 버튼을 놓으면 꼬리는 약 0.8초 안에 뒤쪽부터 흐려집니다. 클릭으로 밝아진 커서는 우클릭에서 고른 시간만큼 강조된 뒤 평소 밝기로 돌아옵니다. 기본값은 1.4초입니다.
- **단축키 변경**은 메뉴 막대의 **설정…**에서 동작 옆 버튼을 클릭하고 새 조합을 누르면 바로 적용됩니다. 전역 단축키에는 ⌘, ⌥, ⌃ 중 하나를 포함하세요. **기본 단축키로 복원**으로 처음 설정을 되돌릴 수 있습니다.

## 캡처와 화면 공유

상단 도구 막대의 **캡처**를 누르고 PNG를 저장할 위치를 선택하세요. 필기 중에는 필기 중인 디스플레이를, 메뉴 막대에서 필기 없이 캡처하면 포인터가 있는 디스플레이를 저장합니다. PNG에는 강의 화면과 펜으로 그린 획이 담깁니다. 저장하거나 취소하면 필기를 이어갈 수 있습니다.

첫 캡처에서 macOS가 화면 녹음 권한을 요청하면 Lines를 허용하세요. 권한을 나중에 바꾸려면 **시스템 설정 → 개인정보 보호 및 보안**의 화면 녹음 항목을 여세요. 온라인 강의에서 필기와 레이저를 수강생에게 보여주려면 화상회의 앱에서 **디스플레이 전체**를 공유하세요.

## 업데이트하기

메뉴 막대에서 **Lines 종료**를 선택하세요. Git으로 받았다면 프로젝트 폴더에서 다음을 실행합니다.

```sh
git pull --ff-only
make run
```

ZIP으로 받았다면 새 ZIP을 풀고 그 폴더에서 `make run`을 실행하세요. 응용 프로그램 폴더에 복사해 쓰는 경우 새로 빌드한 앱으로 교체하세요.
